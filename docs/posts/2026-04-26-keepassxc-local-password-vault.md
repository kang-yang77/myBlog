# KeePassXC：本地密码保险柜

在数字化时代，我们每天都要面对层出不穷的密码和敏感信息：各大平台的 API Key、数据库密码、服务器账密……如何安全地管理这些“数字钥匙”？答案就是 KeePassXC。

## 1. 它的核心作用是什么？

KeePassXC 是一款免费、开源且跨平台的**本地密码管理软件**。它的核心作用是**安全地存储敏感信息**——无论是 API Key、数据库密码，还是服务器账密，它都能帮你妥善保管。

**核心优势：**

- **绝对的本地化：** 你的所有密码都会被高强度加密并打包成一个独立的 `.kdbx` 文件。这个文件完全存放在你的个人电脑硬盘里，不主动联网、不上传云端，从物理层面杜绝了网络批量泄露的风险。
- **加密性强：** 即使黑客拿到了你的 `.kdbx` 文件，以目前的算力也几乎无法暴力破解。你的秘密，只属于你。
- **跨平台通用：** 在 Windows、macOS 和 Linux 上都能原生流畅运行，且 `.kdbx` 文件完全互通。无论你使用什么操作系统，都能轻松管理密码。

## 2. 核心使用流程（只需三步）

使用 KeePassXC 管理密码，只需三个简单步骤。

### 第一步：打造保险柜（新建数据库）

1. 前往官方网站 [keepassxc.org](https://keepassxc.org/)，下载对应你操作系统的安装包并安装。
2. 打开 KeePassXC，点击主界面的 **“新建数据库” (Create new database)**。
3. 跟随指引，为这个数据库命名，并将生成的 `.kdbx` 文件保存在你电脑上稳妥的位置（例如“文档”文件夹）。你也可以结合 OneDrive 或 iCloud 等云存储服务，实现自动同步备份。

### 第二步：设置终极防线（设置主密码）

在建立数据库时，系统会强制要求你设置一个 **主密码 (Master Password)**。这是你进入密码保险柜的唯一钥匙，**请务必牢记**——如果忘记，你将无法恢复任何数据。

**小贴士：** 建议使用一个长且复杂的密码，或者结合密码管理器（如 Bitwarden）来生成和记忆。

### 第三步：存入你的 API Key（添加新条目）

1. 成功进入数据库界面后，点击上方工具栏的 **“添加新条目” (Add new entry)** 图标（通常是一个带有加号的钥匙图标）。
2. 在弹出的信息表单中填写：
   - **标题 (Title):** 填写容易识别的名称，例如 `OpenRouter API Key`。
   - **用户名 (Username):** 可以填写你注册该平台的邮箱，不需要的话可留空。
   - **密码 (Password):** 将你申请到的 `sk-or-xxxxxx` 密钥粘贴于此。
3. 点击 **“确定” (OK)**。
4. **最后一步千万别忘：** 按下 `Ctrl + S` (Windows/Linux) 或 `Cmd + S` (Mac) 将更改保存到数据库文件中！只有保存后，你的新条目才会被永久锁定在保险柜里。

## 结语

KeePassXC 是一个简单而强大的工具，它让你彻底掌控自己的密码安全。从今天开始，把那些散落在记事本、邮件或浏览器里的敏感信息，统统锁进这个本地密码保险柜吧。安全，从第一步开始。
