# About

你好，我是 Yang Kang。

我主要关注三类东西：

1. Java 后端系统设计，尤其是那些会在真实流量、缓存一致性、分层架构和部署链路里暴露问题的部分。
2. AI 应用落地，特别是把 RAG、Agent 或自动化流程真正嵌进业务和个人工作流的方式。
3. 长期写作本身。我希望博客不是“堆内容”，而是一种持续梳理思考、持续发布作品的机制。

这个站点现在同时保留了两层能力：

- 前台是一个偏长文、偏阅读体验的个人博客。
- 后台则在逐步演化成一个适合个人作者使用的内容工作台，支持草稿、状态流转、分类标签和视觉配置。

如果你也在写后端、做 AI 项目，或者想把个人博客做成长期作品，我们大概率会聊得来。
